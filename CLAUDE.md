# CLAUDE.md

This repository's working agreement lives in **[AGENTS.md](AGENTS.md)**. Read it
first and follow it; it is the single source of truth for project structure,
build/test commands, coding style, testing expectations, commit/PR rules, remote
CI etiquette, and security/configuration guidance.

Do not duplicate those rules here. If a convention changes, update `AGENTS.md`.

Additional context worth loading when relevant:

- `SPEC.md` — task list (`T*`), invariants (`V*`), and backprop log (`B*`).
  Spec work is committed with the matching `T<n>:` or `backprop §B.<n>` prefix.
- `README.md` — user-facing install and usage for both platforms.
- `docs/` — platform notes: `windows.md`, `linux.md`, `gnome-wayland.md`,
  `app-shell-architecture.md`, `paste-delays.md`, `settings-e2e-matrix.md`.
